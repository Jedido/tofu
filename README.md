# tofu

## Project setup (Windows)
1. install Node.js
2. If using the Youtube API, add YOUTUBE_API_KEY in your .env.local
3. run `npm install`

### Compiles and hot-reloads for development
In two different terminals:
```
npm run dev:client
npm run dev:server
```

### Builds and deploys production
```
npm run prod
```

### Lints files
```
npm run lint
```
Auto-fix errors:
```
npm run lint:fix
```
